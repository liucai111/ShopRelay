## 公共测试与历史回放

GitHub 核心检查的范围见 [CI 定义](../.github/workflows/core.yml)。历史回放工具及测试代码仍保留，但依赖的运行原档不公开，因此不能以全仓 `pytest` 作为公共检出的无条件验收命令。缺少原档不通过复制真实日志或伪造数据解决；需要新增公共回归时，应制作自包含的合成 fixture。

默认入口为 [本地运行指南](getting-started.md)，高级历史部署配置不会自动赋予新一轮模型调用或数据访问权限。清理未修改线上服务、业务数据库、付费调用预算或历史评测结论。

## 发布边界

1. **独立发布不携带旧历史。** 原仓库的历史保留不动；公开发布从当前源码建立新的首次提交。不要再把原仓库的旧分支或标签推送到公共仓库。
2. **依赖安装仍待新环境验证。** 后端验证使用独立源码副本和已有依赖，前端验证使用本机依赖；不是全新机器安装，也不是 GitHub Actions 远端运行。
3. **不是生产部署认证。** 本次没有重新运行付费模型、数据库集成与容量评测。项目质量仍以 [评测摘要](evaluation.md) 中明确的版本和分母为准。
4. **第三方许可。** 项目代码采用 MIT；外部模型、依赖及参考资源不因本项目许可证而变更授权。
